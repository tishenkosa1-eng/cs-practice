git diff показывает изменения в коде

git show отображает полную информацию о коммите

git log показывает историю коммитов

git log -S ищет коммиты, в которых была добавлена или удалена определенная строка в коде

git blame показывает, кто, когда и в каком коммите последним изменил каждую конкретную строчку кода в файле
