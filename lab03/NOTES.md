&#x20; git restore— сбрасывает все незакоммиченные изменения в текущем рабочем файле, возвращая файл к состоянию последнего коммита

&#x20; git restore --source=— не просто сбрасывает изменения, а заменяет рабочую версию файла его копией из конкретного указанного коммита в истории (например, из HEAD\~2).

&#x20; Если запустить git restore, все текущие незакоммиченные правки будут безвозвратно удалены. Так как они не были зафиксированы в базе данных Git, восстановить их будет невозможно.
