Рабочая папка - файлы на диске, которые я редактирую; git видит изменения, но не сохраняет их.



Индекс  - промежуточная область, куда я добавляю изменения через git add. Это черновик будущего коммита.



Коммит - зафиксированный снимок индекса в истории. У него есть хеш, автор, дата и сообщение



git - система контроля версий, работает локально на компьютере
GitHub - платформа для облачного хранения git-репозиториев и совместной работы



git diff
сравнивает рабочую папку с индексом, показывает изменения, которые еще не добавили в индекс

git diff --staged
сравнивает индекс с последним коммитом



Использованные команды

состояние рабочей папки и индекса

git diff
сравнивает рабочую папку с индексом, показывает изменения, которые еще не добавили в индекс

git diff --staged
сравнивает индекс с последним коммитом



Ветки

Ветка - подвижный указатель на коммит

Что происходит с веткой при новом коммите?
Указатель текущей ветки сдвигается на новый коммит, другие ветки остаются на своих местах

Что делает слияние?
Объединяет изменения одной ветки в другую. Создается merge-коммит, в котором соединяются истории обеих веток.
